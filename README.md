# Finetech Marketplace App

A lightweight marketplace web app prototype built with plain HTML, CSS, and JavaScript.

## Features

### Shopper features
1. **Product discovery** with category tabs and a featured products section.
2. **Search** by product title.
3. **Filter** by category and maximum price.
4. **Sort** by relevance, price (low-high / high-low), and rating.
5. **Wishlist** to save products for later.
6. **Cart management** (add/remove items and view running total).
7. **Checkout summary** with simulated order placement.
8. **Order history** showing placed orders and statuses.

### Seller features
9. **Seller dashboard** to add new products.
10. **Inventory visibility** through live product grid updates.
11. **Sales snapshot** with basic revenue/order counters.

### Trust and engagement features
12. **Ratings and reviews** displayed per product.
13. **Buyer-seller messaging mock** with local conversation history.
14. **Badges** for featured and trusted sellers.

### Platform features
15. **Responsive UI** for desktop and mobile layouts.
16. **Client-side state management** without external dependencies.
17. **Seed data** to quickly demo marketplace behavior.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
